## 🧩 Sobre el proyecto

Esta aplicación ha sido desarrollada como parte de la asignatura de **Diseño** dentro del ciclo formativo de **Desarrollo de Aplicaciones Multiplataforma (DAM)**.

El objetivo principal del proyecto es aplicar los conceptos fundamentales de diseño de interfaces, centrándose en la experiencia de usuario (UX) y la interfaz visual (UI), mediante la creación de una aplicación funcional, intuitiva y visualmente atractiva.

---

## 🎯 Objetivos del proyecto

- Diseñar una interfaz clara, moderna y usable  
- Aplicar principios de jerarquía visual y accesibilidad  
- Desarrollar una experiencia de usuario intuitiva  
- Estructurar correctamente una aplicación  
- Aplicar buenas prácticas de desarrollo  

---

## 🚀 Funcionalidades

- 🖥️ Interfaz limpia y organizada  
- 🔄 Navegación fluida entre pantallas  
- 📱 Diseño adaptable a distintos dispositivos  
- ⚡ Experiencia de usuario optimizada
